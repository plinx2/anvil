# PR 作成担当(バックグラウンドロール)

ロール一覧は [../roles.md](../roles.md)。**バックグラウンドロール**([roles.md](../roles.md))。

## 役割

PR の**本文を作成する**(確定)。**PR 自体は anvil が作る**。

## 動くタイミング(確定)

- チケットが**完了前ゲートに到達したとき**(最初の到達で PR を作り、差し戻し後の再到達では既存の PR を更新する)。
- リモートリポジトリが設定されているリポジトリだけが対象。スパイクのチケットは対象外(ブランチも PR も作らない)。

## 起動の形(確定)

- **バックグラウンドで動く**。herdr のペインは使わない。anvil が内部で `claude` を実行する。人間との会話は無い。
- 状態に紐づくエージェントの起動・終了の対象ではない。PR を作るたびに実行して、終わったら終わる。

## モデル(確定)

- **Haiku 5.5**(`claude-haiku-5-5`)。決まった入力から決まった出力を作る、軽い仕事のため([../roles.md](../roles.md))。

## 入力

- チケットの各種エントリ(実装方針、デザイン設計、機能設計、テスト設計、実装の結果、動作確認)。
- 対象リポジトリごとの差分(ブランチ)。
- プロジェクトコンテキスト(PR の書き方の規約があれば)。

## 出力

- PR の本文(タイトルを含む)。
- anvil が、その本文で PR を作り、**PR の URL や識別子をチケットに登録する**(確定)。複数のリポジトリが対象のときは、リポジトリごとに登録する。

## 細部(確定)

- **本文に書くこと**: タイトル、要約(ペイン、ゲイン、AC)、変更の理由、確かめ方(機能動作確認とデザイン確認の結果)、レビュワーへの申し送り。**anvil のチケットへのリンクは入れない**(ローカルの anvil は、チームのほかのメンバーが見られないため)。書き方の規約があれば、このロールのロール別ページ(`roles/pr-writer.md`)に書く。
- **差し戻し後の再到達**: 本文を、最新のエントリを反映して更新する。PR のコメントには触らない。
- **失敗したとき**(PR の作成に失敗した、リモートに繋がらない): 完了前ゲートへの到達は止めない。チケットに「PR 作成失敗」と表示し、ダッシュボードにも出す。詳細画面に「PR を作り直す」操作を置く。
- **ベースブランチ**: リポジトリのデフォルトブランチ(ブランチの元と同じ)。
