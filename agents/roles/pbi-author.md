# PBI 起票担当

ロール一覧は [../roles.md](../roles.md)。

## 役割

簡単な「やりたいこと」から、**タイトル・ペイン・ゲイン・AC** に整えて、チケットを起票する(確定)。形はプロジェクトコンテキストに従う。

## 呼び出される場面(確定)

- GUI から、人間が起票するとき。
- AI(人間の指示を受けた Claude)から、MCP またはスキルで起票するとき。いずれも、**人間が書いた、または指示した**内容が入力になる。
- AC 担当または実装方針担当から、**チケットの分割**を依頼されたとき。

## 入力

- 簡単なやりたいこと(人間の言葉)。
- 分割の依頼のときは、分割の内容(分け方、各チケットの範囲)。
- プロジェクトコンテキスト(書く項目、書き方)。

## やること

- 入力を、タイトル・ペイン・ゲイン・AC に整える。分割の依頼でも、**そのまま使わず、整え直す**(確定)。
- **ペイン・ゲインが読み取れない、または足りないときは、推測で書かずに、人間に質問する**(確定)。分割の依頼でも同じ。
- 起票時に、**自動ゲート承認フラグ**と**依存関係**は、**人間の指定があれば**設定する(確定)。指定がなければ設定しない。GUI でも AI でも、人間が書くか指示している。
- **slug**: 人間の指定があればそれを使う。未指定なら、内容から考える(確定)。
- 起票したチケットは、**既定では TODO** で止まる(確定)。**状態の指定があれば、その状態**で起票する(スパイクなど)。リファインに進めるのは、人間、または人間に依頼された Claude。

## 出力

- 起票したチケット(タイトル、内容)。内容の形はプロジェクトコンテキストに従う。

## 起動の形(確定)

- **herdr 上に、起票エージェントを起動する**。anvil が内部で `claude` を実行するだけの形は取らない(質問の経路が作れないため)。
- 人間への質問は、**herdr のペインでの会話**で行う。承認待ちフラグは使わない(チケットがまだ無いため)。
- 他のロールのように、チケットの状態に紐づく起動・終了の対象ではない。**起票のたびに起動し、起票が終わったら終了する**。
- **GUI から**(確定): 「起票」ボタンを押すと、**やりたいことを入力する UI(複数行)**を表示する。入力して「起票」を押すと、ペインを起動し、やりたいことを渡して、会話を始める。
- **起票後は、すぐに終了する**(確定)。
- **起票後の更新**(確定): 別途、人間が使う Claude から、MCP 経由でチケットを更新させる。起票エージェントは、更新のために残さない。
- **分割のとき**(確定): 起票ボタンの動き(入力 → ペイン起動 → 会話 → 起票 → 終了)を、**分割した件数だけ複数回行う**。AI(AC 担当、実装方針担当)からは、MCP で同じ動きを依頼する。

## スコープ外

- AC の中身の良し悪しの判断(AC 担当の仕事)。
- 実装方針や設計。
- リファイン以降の状態遷移。

## 細部(確定)

- **AI からの起動**: 人間が使う Claude が MCP で渡すのは、起票の依頼 API と同じ入力(やりたいこと、種別、開始状態、slug、依存先、自動ゲート承認フラグ)。
- **分割時の複数件**: 起票エージェントは、**1 件ずつ順に起動する**(人間の質問が 1 つずつになり、ペインも増えない)。分割元の情報は、各「やりたいこと」の本文に含めて渡す(元は破棄されるため)。
- **起票エージェントのセッション ID**: 起動の記録を、チケット未定で先に作り、起票されたときに anvil がチケットへ紐づける。
- **終了**: 起票を検知して、anvil が終了させる。
- **MCP のチケット更新**: 誰でもできる(anvil-features.md §4)。
